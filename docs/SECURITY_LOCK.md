# قفل رمز عبور

کارهای حساس داخل برنامه پشت یک رمز عبور قرار دارند.

## چه چیزهایی قفل است
ورود به صفحه‌ی **تنظیمات** رمز می‌خواهد و تمام این کارها داخل آن است:
- تغییر **آدرس سرور** و سایر تنظیمات،
- خاموش‌کردن **همگام‌سازی خودکار** و سوئیچ‌ها،
- **حذف کامل اطلاعات**،
- **تغییر رمز عبور**.

رمز پیش‌فرض: `Ali@101010`

## تغییر رمز
تنظیمات → بخش «رمز عبور مدیریت» → رمز جدید را وارد و «تغییر رمز عبور» را بزنید.

## نکات امنیتی (صادقانه)
- رمز به‌صورت **هش SHA-256** ذخیره می‌شود (در حافظه‌ی رمزنگاری‌شده‌ی اندروید)، نه متن ساده.
- قفل پس از هر بار **بسته‌شدن کامل برنامه** دوباره فعال می‌شود.
- این قفل جلوی استفاده‌ی عادی/اتفاقی را می‌گیرد؛ اما یک **قفلِ درون‌برنامه‌ای** است و نمی‌تواند جلوی **حذف برنامه از تنظیمات اندروید** را بگیرد.
- اگر می‌خواهید حذف/غیرفعال‌سازی در سطح سیستم هم سخت شود، اپ را **Device Owner** کنید (نگاه کنید به `docs/AUTO_UPDATE.md`). در این حالت تا وقتی device-owner فعال است، اندروید اجازه‌ی حذف برنامه را نمی‌دهد.
- پس از «حذف کامل اطلاعات»، رمز به مقدار پیش‌فرض (`Ali@101010`) بازمی‌گردد.
