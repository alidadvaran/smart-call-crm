# Smart Call CRM

اپلیکیشن شخصی مدیریت تماس‌ها برای **دو گوشی اندرویدی یک کاربر** + بک‌اند مرکزی و گزارش ایمیلی.

این نرم‌افزار فقط برای استفاده‌ی شخصی روی گوشی‌های خودِ کاربر طراحی شده است: سوابق تماس هر گوشی با **رضایت صریح** کاربر خوانده می‌شود، صدای مکالمه **ضبط نمی‌شود**، و نیازی به **Root** ندارد.

---

## اجزا

| پوشه | توضیح |
|------|-------|
| `app/` | اپ اندروید (Kotlin + Jetpack Compose + Room + WorkManager)، رابط فارسی/RTL |
| `server/` | بک‌اند مرکزی (Node.js + Express + PostgreSQL + Nodemailer) |
| `docs/` | راهنمای نصب، مجوزها، سرور، ایمیل، به‌روزرسانی و آزمون‌های پذیرش |
| `scripts/` | اسکریپت‌های کمکی (ساخت کلید امضا) |

## قابلیت‌ها

- ثبت تماس‌های ورودی/خروجی/ازدست‌رفته/ردشده با شماره، نام مخاطب، زمان، **مدت واقعی مکالمه** و شناسه‌ی سیم‌کارت.
- اسکن دوره‌ای پس‌زمینه با WorkManager + ادامه پس از Restart (BootReceiver).
- ذخیره‌ی کامل آفلاین (Room) و همگام‌سازی idempotent با سرور (بدون ارسال تکراری).
- CRM: پروفایل مشتری، وضعیت فروش (New → Contacted → Qualified → Follow-up → Won/Lost)، یادداشت، پیگیری.
- پروفایل مشترک برای شماره‌ی مشترک بین دو گوشی، با حفظ جداگانه‌ی تماس‌های هر گوشی.
- گزارش ایمیلی روزانه/هفتگی/دستی (HTML + CSV) از سمت سرور؛ رمز ایمیل هرگز در APK نیست.
- داشبورد وب مرکزی برای مشاهده‌ی تجمیعی هر دو گوشی.

## وضعیت ساخت (صادقانه)

- کل سورس اپ و بک‌اند نوشته و از نظر ساختار کامل است. فایل‌های بک‌اند با `node --check` از نظر نحوی تأیید شده‌اند.
- **ساخت APK** نیاز به Android SDK از میزبان `dl.google.com` دارد. در محیط ابری توسعه این میزبان مسدود بود؛ APK باید در محیطی ساخته شود که به آن دسترسی دارد (ماشین شما، CI گیت‌هاب، یا محیط ابری پس از آزادسازی دامنه).
- **آزمون‌های پذیرش روی گوشی واقعی هنوز اجرا نشده‌اند** (نیازمند دو دستگاه فیزیکی). فهرست کامل در `docs/ACCEPTANCE_TESTS.md`.

## ساخت سریع

```bash
# در ریشه‌ی پروژه، با Android SDK نصب‌شده و متغیر ANDROID_HOME:
./gradlew :app:assembleDebug        # APK دیباگ
./gradlew :app:assembleRelease      # APK ریلیز (با keystore.properties امضا می‌شود)
```

جزئیات در `docs/BUILD.md`. راه‌اندازی سرور در `docs/SERVER_SETUP.md`.
